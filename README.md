
# Hello World 👋

Minha primeira missão de desenvolvimento web.

## Sobre o projeto

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em programação.

O objetivo é criar uma página simples que apresente a mensagem "Hello World" e meu nome, utilizando HTML e CSS.

## Tecnologias utilizadas

- HTML5 — estrutura da página
- CSS3 — cores e estilização
- Git — controle de versões
- GitHub — hospedagem do código

## O que aprendi

- Criar a estrutura básica de uma página HTML.
- Utilizar títulos com as tags h1 e h2.
- Aplicar estilos com CSS.
- Conectar arquivos HTML e CSS.
- Registrar alterações utilizando Git.
- Publicar um repositório no GitHub.
